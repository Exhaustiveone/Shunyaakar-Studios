# Backend

The site's backend lives in **[`backend/`](backend/)**: a small Node.js server that serves the website and the private `/desk`, and stores contact enquiries and newsletter sign-ups in Supabase Postgres.

- **Deploy on Render, set up the admin login, security details:** [backend/README.md](backend/README.md)
- **Render configuration:** [render.yaml](render.yaml)
- **Database tables:** [backend/db/schema.sql](backend/db/schema.sql)
